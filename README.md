# SpeakerIris

SpeakerIris utilizes real-time distributed processing to manage large-scale voice datasets and auto-scaling architectures.

With SpeakerIris, you get a lightweight tool that stays out of your way.

**What you get**

- SpeakerIris utilizes real-time distributed processing
- to manage large-scale voice datasets
- and auto-scaling architectures

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/SpeakerIris.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

To configure SpeakerIris, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
